# ConversationLoopProject

This project was created for ECE 309 Project 2. There was a read me file and specifications file for me to follow in order to create this project. This project showcases using rule of five, getters, and dynamic array allocation for the purposes of creating a mock mini-LLM. The files created/edited/and published were conversation.h, message.h, sentinel_scanner.h, conversation.cpp, sentinel_scanner.cpp, test_p2.cpp, and design-log-p2.md. This project is a part of the semester long project in the ECE 309 Class at North Carolina State University.
